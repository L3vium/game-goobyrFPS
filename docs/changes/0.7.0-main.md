# 0.7.0 — orchestrator notes

- **Searchers open hiding spots.** During a search, at each stop of the sweep, a guard opens the
  nearest closet, dumpster or crate within 7 m that lies within 15 m of the search centre and that
  he has not checked yet (60% chance per stop). A player hiding inside is pulled out
  (`PlayerAvatar.PullOutOfHidingRpc`, host → owner) and spotted at once. Hiding still beats a
  casual glance: only searches open spots. `HidingSpot.All` is the registry.
- **Players spawn with bare fists out** (`WeaponHolder._holsterOnSpawn`): a drawn gun is a crime
  outside public areas, so the loadout is one wheel turn away.
- **Shared-editor tooling**: `Tools/unity_mcp.py` (per-agent sessions, editor lock with a fair
  queue, heavy tools refuse without the lock) and `Tools/commit.py` (path-only commits under a
  mutex, push hold during LFS build pushes).

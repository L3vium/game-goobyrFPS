# Goobyr FPS — working agreements

See also `D:\_Project\AGENTS.md` (Unity-first, new Input System only, no hand-written `.meta`,
validate through Unity MCP, `tasks/lessons.md` after every correction).

## Git

- **Work on `dev`.** `main` only ever receives `dev` through the merge at the end of a prompt.
- **Commit and push every change, one change at a time** to `origin dev`. Several agents can share
  this checkout: commit with `python Tools/commit.py "Subject" [-m "body"] <paths…>` (stages and
  commits only those paths, with their `.meta`, under a mutex, then pushes). Never `git add -A`,
  `commit -a`, stash, reset, checkout or pull in the shared checkout.
- **End of every prompt:** player build (`Goobyr/Build/Player`, output `Builds/Windows/GoobyrFPS.exe`,
  versioned through LFS), commit + push it, then release main **without checking it out** (a
  checkout would reimport the whole project under the open editor):
  `git merge-base --is-ancestor main dev` (must succeed), then
  `git update-ref refs/heads/main $(git commit-tree "dev^{tree}" -p main -p dev -m "Release x.y.z")`
  and `git push origin main`. Same result as `merge --no-ff`: main gets its own merge commits and
  stays a distinct line in Fork.

## Unity access

The editor stays open with MCP for Unity on `http://localhost:8084/mcp`, driven over HTTP with
`python Tools/unity_mcp.py <tool> '<json>'`; batchmode is not available (the project is locked).
Compile, console, tests, builders and the player build all go through MCP (`refresh_unity`,
`read_console`, `run_tests`, `execute_menu_item`). Never launch, close or restart the editor.

When several agents work at once, each sets `UNITY_MCP_AGENT=<name>` and takes the editor lock
(`unity_mcp.py lock <minutes> <what>` / `unlock` / `who`) for anything that changes the editor:
play mode, scenes, builders, refresh/compile, tests, bakes, builds. Editor Auto Refresh is off and
scripts recompile after play mode ends, so refresh explicitly; only save `.cs` that compiles (no
asmdefs: every save recompiles the whole project for everyone).

## Generated content

Maps, materials, meshes, prefabs, data assets and SFX are **generated by editor builders**
(`Goobyr → Build → …`, sources in `Assets/_Game/Editor/`). A hand edit to a generated asset is
overwritten by the next build: change the builder. Blender assets come from scripts in
`Tools/Blender/**` (exported FBX under `Assets/_Game/Art/`); Blender exports go to a staging folder
and are copied into Assets under the editor lock.

## Code
